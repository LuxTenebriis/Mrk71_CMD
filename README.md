# Mrk71_CMD

This is an edit of Sophia Troshynski’s `3Final_Analysis.ipynb` to run in
my google Google Colab. 

## Notebook Layout

- **Setup:** Imports packages, defines functions, and sets file paths.
- **Load and Process Data:** Loads catalogs, corrects for extinction,
  applies quality criteria, and substitutes aperture photometry where available.
- **Edit Selected Stars:** Applies the original manual group-editing procedure.
- **Stats:** Calculates stellar counts, percentages, and uncertainties.
- **Plotting:** Creates optical, FUV, and FUV–optical diagrams.
- **Miscellaneous:** Contains additional individual-star tests and edits;
  their role in the reference run still needs confirmation.

U-M GPT was used to assist with Python syntax, debugging, code organization,
and documentation.
